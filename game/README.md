# GOAL RUSH 3D — standalone build

`goal-rush.html` is the full game (the claude.ai artifact) as one file. Open it directly in Chrome or Edge
(double-click it, or drag it into the browser) to **play with a controller**: claude.ai runs artifacts in a
frame that blocks the Gamepad API, so a controller only works when the game is its own page
(this file, or the same file hosted on Netlify / GitHub Pages).

Supported controllers: Xbox, PlayStation, Switch Pro and generic "standard" pads — connect it, then press any button.

`night_patch.py` produces the current build from the artifact's previous version:
night sky and fog, cool white key light, glowing lamps on the stadium's eight floodlight poles,
stronger mowing stripes, bolder kits (Home Royal, Midnight, Neon Street, Shadow), and harder, earlier AI strikes
with a faster ball.
